# xdy-skills

A collection of agent skills by xdy for work and projects. Share this repository with your agent and ask it to explain the skills and suggest a combination for your task.

> Explore https://github.com/dirasx/xdy-skills, explain what each skill does, and suggest which ones to use together for my task.

## Coursework and AutoCAD

| Skill | Purpose |
| --- | --- |
| [course-project](skills/coursework/course-project/SKILL.md) | Plan and manage coursework, calculations, reports, and drawings across sessions. |
| [dwg-review](skills/coursework/autocad-skills/dwg-review/SKILL.md) | Inspect DWG drawings and compare changes between versions. |
| [drawing-pdf-review](skills/coursework/autocad-skills/drawing-pdf-review/SKILL.md) | Review plotted drawing sheets in PDF. |
| [drawing-redraw](skills/coursework/autocad-skills/drawing-redraw/SKILL.md) | Reconstruct drawings from DWG, PDF, or images. |
| [xdy-autocad-mcp](skills/coursework/autocad-skills/xdy-autocad-mcp/SKILL.md) | Work with a connected AutoCAD MCP server and verify DWG geometry. |

For coursework with drawings, combine `course-project` with the drawing skills that match the task. Use `xdy-autocad-mcp` when working through an AutoCAD MCP server. The server is configured separately. [AutoCAD collection and setup](skills/coursework/autocad-skills/README.md).

[Browse on skills.sh](https://skills.sh/dirasx/xdy-skills)

## Скиллы xdy

Мой сборник скиллов для ИИ-агентов, которые помогают в работе и проектах. Можно отправить ссылку агенту и попросить его рассказать о скиллах и подобрать нужную связку.

> Изучи https://github.com/dirasx/xdy-skills, расскажи, какие здесь есть скиллы и для чего они нужны. Предложи, какие из них стоит использовать вместе для моей задачи.

### Курсовые и AutoCAD

| Скилл | Для чего |
| --- | --- |
| [course-project](skills/coursework/course-project/SKILL.md) | Ведение курсовой, планирование, расчёты, записка и чертежи. |
| [dwg-review](skills/coursework/autocad-skills/dwg-review/SKILL.md) | Проверка DWG и сравнение изменений между версиями. |
| [drawing-pdf-review](skills/coursework/autocad-skills/drawing-pdf-review/SKILL.md) | Проверка напечатанных листов чертежей в PDF. |
| [drawing-redraw](skills/coursework/autocad-skills/drawing-redraw/SKILL.md) | Восстановление чертежей из DWG, PDF или изображений. |
| [xdy-autocad-mcp](skills/coursework/autocad-skills/xdy-autocad-mcp/SKILL.md) | Работа через подключённый AutoCAD MCP и проверка геометрии DWG. |

Для курсовой с чертежами используй `course-project` и подходящие скиллы для чертежей. Для работы через AutoCAD MCP пригодится `xdy-autocad-mcp`. Сервер подключается отдельно. [Скиллы AutoCAD и настройка](skills/coursework/autocad-skills/README.md).
