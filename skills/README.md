# Skills

## Coursework and AutoCAD

| Skill | When to use it |
| --- | --- |
| [course-project](coursework/course-project/SKILL.md) | Plan and manage coursework across sessions, from the assignment and calculations to the report and drawings. |
| [dwg-review](coursework/autocad-skills/dwg-review/SKILL.md) | Inspect a DWG, review edits, and compare saved drawing versions. |
| [drawing-pdf-review](coursework/autocad-skills/drawing-pdf-review/SKILL.md) | Review plotted drawing sheets in PDF and report findings by location. |
| [drawing-redraw](coursework/autocad-skills/drawing-redraw/SKILL.md) | Reconstruct a drawing from a DWG, vector PDF, or image with known dimensions. |
| [xdy-autocad-mcp](coursework/autocad-skills/xdy-autocad-mcp/SKILL.md) | Draft, edit, measure, and verify drawings through a connected AutoCAD MCP server. |

For coursework with drawings, use `course-project` with the relevant drawing skills. For DWG work through MCP, add `xdy-autocad-mcp`; the MCP server is connected separately. Use `drawing-pdf-review` for plotted sheets and `drawing-redraw` when reconstruction is needed. [AutoCAD setup and details](coursework/autocad-skills/README.md).

## Скиллы для курсовой и AutoCAD

| Скилл | Когда использовать |
| --- | --- |
| [course-project](coursework/course-project/SKILL.md) | Вести курсовую в разных чатах: от задания и расчётов до записки и чертежей. |
| [dwg-review](coursework/autocad-skills/dwg-review/SKILL.md) | Проверить DWG, внесённые правки и изменения между сохранёнными версиями. |
| [drawing-pdf-review](coursework/autocad-skills/drawing-pdf-review/SKILL.md) | Проверить листы чертежей в PDF и указать места замечаний. |
| [drawing-redraw](coursework/autocad-skills/drawing-redraw/SKILL.md) | Восстановить чертёж из DWG, векторного PDF или изображения с известными размерами. |
| [xdy-autocad-mcp](coursework/autocad-skills/xdy-autocad-mcp/SKILL.md) | Чертить, править, измерять и проверять DWG через подключённый AutoCAD MCP. |

Для курсовой с чертежами используй `course-project` и подходящие скиллы для чертежей. Для работы с DWG через MCP добавь `xdy-autocad-mcp`; сервер MCP подключается отдельно. `drawing-pdf-review` поможет проверить напечатанные листы, а `drawing-redraw` — восстановить чертёж. [Настройка AutoCAD и подробности](coursework/autocad-skills/README.md).
