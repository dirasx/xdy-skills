# Шаблон ведения проекта

При вызове `$xdy-docsproduct` прочитай целиком [assets/WORKFLOW.md](assets/WORKFLOW.md) из каталога этого скилла. Выведи его дословно одним блоком `markdown` для копирования, сохранив переносы строк.

После закрывающей строки блока отдельным абзацем напиши: «Принял правила из твоего скилла и готов работать по ним в этом проекте». Это подтверждение, что ты будешь следовать правилам в текущем чате.

Используй тот же полный шаблон во всех проектах. Оставь заголовок «Как ведём проект» и сохрани все разделы и имена файлов. Для обычного вызова читай только шаблон. Не подставляй название, пути или настройки текущего репозитория и не меняй его файлы.

Адаптация или запись в репозиторий допустимы только по прямой просьбе пользователя. При запросе на сохранение полного шаблона перенеси его дословно.
