# Шаблон ведения проекта Lume

При вызове `$xdy-docsproduct` прочитай целиком [assets/WORKFLOW.md](assets/WORKFLOW.md) из каталога этого скилла и выведи его содержимое дословно в одном блоке `markdown` для копирования. Ответ состоит только из этого блока.

Выводи тот же шаблон в любом чате и репозитории. Сохраняй русский текст, название Lume, заголовки, пути, примеры и раздел про Sites. Контекст текущего проекта, его файлы и локальные изменения не влияют на шаблон. Для обычного вызова читай только файл шаблона. Не добавляй вступление, сводку по репозиторию или инструкции по применению и не меняй файлы проекта.

Адаптация или запись в репозиторий допустимы только по прямой просьбе пользователя. При запросе на сохранение полного шаблона перенеси его дословно.
